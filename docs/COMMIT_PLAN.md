# Rencana Commit GitHub

Jalankan commit sesuai progres kerja yang benar-benar telah selesai:

1. `chore: initialize Flutter project structure`
2. `feat: add local quiz question model and dataset`
3. `feat: implement home screen and name input`
4. `feat: implement quiz flow and answer selection`
5. `feat: calculate score and display result review`
6. `feat: add provider state management and theme toggle`
7. `style: add responsive layout and custom typography`
8. `docs: add screenshots, mockup, and presentation details`

Contoh perintah:

```bash
git init
git add .
git commit -m "chore: initialize Flutter project structure"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Jangan gunakan semua pesan commit sekaligus di akhir. Buat commit setiap kali fitur yang sesuai benar-benar selesai.
